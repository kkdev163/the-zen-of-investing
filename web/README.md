# 余量 Web

家庭房贷、长期投资与退休现金流的 30 年情景推演工具。

## 本地运行

```bash
npm run serve
```

打开 `http://127.0.0.1:4173`。ES Modules 需要通过 HTTP 服务加载，不建议直接使用 `file://` 打开。

## 测试

```bash
npm test
```

项目没有运行时依赖，测试使用 Node.js 内置测试运行器。

## 结构

- `index.html`：语义化页面结构与表单。
- `styles.css`：桌面和移动端样式。
- `js/finance.js`：贷款、投资、现金流和退休计算。
- `js/chart.js`：无第三方依赖的 Canvas 趋势图。
- `js/app.js`：表单状态、版本切换与结果渲染。
- `tests/finance.test.js`：金融模型的回归测试。

## 产品口径

- 基础版：贷款参数、还款方式、纳指初始仓位和每月定投。
- 付费版：在基础版之上增加存款、收入、开支和退休收入切换。
- 投资收益按有效年化收益率折算为月收益率，定投发生在每月末。
- 现金余额允许为负，负数表示尚未覆盖的累计现金缺口。
